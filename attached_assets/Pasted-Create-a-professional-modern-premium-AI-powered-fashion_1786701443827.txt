Create a professional, modern, premium AI-powered fashion styling website called “StyleAI” — an intelligent personal AI stylist that helps users create outfits, manage their wardrobe, discover fashion trends, and shop complete looks.

The website should look like a real production-ready fashion-tech startup, not a basic student project. Use a clean, elegant, minimal fashion aesthetic with premium typography, smooth animations, beautiful clothing imagery, rounded cards, subtle shadows, spacious layouts, and a responsive design for desktop, tablet, and mobile.

CORE CONCEPT:
“Your AI Stylist That Knows Your Wardrobe.”

The main user flow should be:
Upload clothes → Build digital wardrobe → Select occasion/weather/style → AI generates outfit → Customize outfit → Get style score → Save outfit → Shop the look.

TECH STACK:
- React
- Tailwind CSS
- React Router
- Framer Motion for animations
- Python + FastAPI backend
- PostgreSQL or MongoDB database
- AI API integration
- Weather API integration
- Computer vision/image processing
- REST APIs
Create the frontend architecture so the backend/API integrations can be connected later.
